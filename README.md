# ⚡ SYNAPSES — Agentic AI & EDA Master Course

A comprehensive, interactive, and visual master course on **Production-Grade Multi-Agent Systems for Analog and Digital Electronic Design Automation**. Built as a fully self-contained, browser-based HTML course — no server required.

## 🚀 Quick Start

Open `index.html` in any modern browser to begin the course.

## 📚 Course Structure

| Module | Title | Topics |
|--------|-------|--------|
| [Module 1](module1.html) | Core Agentic Architectures | Supervisor-Worker, Consensus, Handoff, LangGraph DAGs |
| [Module 2](module2.html) | SOTA AI EDA Solutions | ChatEDA/AutoMage, RTLCoder, EDAid Divergent Thought |
| [Module 3](module3.html) | Specialized Analog Design | AnalogCoder/Pro, AnalogSAGE, GENIE-ASI, Schemato |
| [Module 4](module4.html) | The Physical Frontier | Feedback Loop Crisis, WPE/STI, Data Wall, Physics Limits |
| [Module 5](module5.html) | Mastery for AI Engineers | MCP, LangGraph advanced patterns, 12 Production Pillars |
| [Module 6](module6.html) | Pedagogical Project | Full self-evolving analog EDA system (Stages A–D) |

## ✨ Features

- **Interactive quizzes** in every module with instant feedback
- **Animated SVG diagrams** for agent workflows and architectures  
- **Syntax-highlighted code examples** in Python with copy buttons
- **Tab systems and accordions** for organized deep-dive content
- **Progress tracking** across all 6 modules (stored in localStorage)
- **Responsive design** — works on desktop, tablet, and mobile
- **Sticky sidebar navigation** with scroll-aware active highlighting

## 🎯 Learning Objectives

By completing this course, you will be able to:

1. Design and implement production-grade Multi-Agent Systems using LangGraph
2. Understand SOTA EDA AI systems: ChatEDA, RTLCoder, and EDAid
3. Build agentic pipelines for analog circuit design using AnalogCoder principles
4. Navigate the physical design challenges: WPE, STI, the Data Wall, and physics limits
5. Implement MCP servers for EDA tools and apply the 12 Production Pillars
6. Build a complete self-evolving analog block designer from NL spec to verified GDS

## 🛠 Technology

- Pure HTML5 / CSS3 / Vanilla JavaScript — no build system or dependencies required
- Works completely offline once loaded
- All code examples use Python (LangChain, LangGraph, PySpice ecosystem)
