Context

The Paradigm Shift in EDA

From AI-assisted manual flows to fully autonomous multi-agent design systems.

🔴
The Productivity Gap
As SoC complexity scales to hundreds of billions of transistors, manual script-based flows have become insufficient. Verification alone now consumes up to 70% of the design cycle.
🤖
From AI4EDA → Agentic EDA
The industry is moving from AI-Assisted automation (static scripts + human oversight) to Agentic EDA: autonomous MAS where agents close the design loop without human intervention.
⚡
Your New Role
In 2026, AI engineers no longer write code — they orchestrate agents. Mastery means designing separation of concerns: one agent generates, a separate Critic Agent validates.
Feature AI-Assisted (AI4EDA) Agentic EDA (2026)
Orchestration Manual (Human Engineer) Autonomous (MAS Supervisor)
Logic Flow Static Tcl/Python Scripts Dynamic Graphs (DAGs/Cycles)
Memory None (Per-execution) Stratified (Evolution/Introspective/Fusion)
Verification Final Check Continuous Inner-Loop Feedback
Outcome Assistant results Self-correcting design closure

Learning Path

Your Journey

A chronological path from foundations to a deployed agentic EDA system.

Foundation
Module 1–2: Architecture & SOTA Systems
Understand MAS design patterns (Supervisor-Worker, Consensus, Handoff) and dive into real-world EDA systems: ChatEDA, RTLCoder, and EDAid. Learn how stateful graph workflows enable iterative design refinement.
Specialization
Module 3–4: Analog Domain & Physical Limits
Explore the unique challenges of analog design: continuous-valued signals, layout parasitics, the feedback loop crisis with SPICE simulation, and physics-grounded reasoning for Joule heating and RF crosstalk.
Mastery
Module 5: Production Engineering
Master MCP (the "USB-C of AI"), LangGraph's persistent checkpointing and time-travel debugging, and all Twelve Pillars needed to move from demo to production-grade enterprise MAS.
Capstone Project
Module 6: Build a Self-Evolving Analog System
Four progressive stages: build an Identification Agent, add a feedback-enhanced Netlist Generator, implement a Multimodal Waveform Debugger using vision LLMs, and finally automate physical layout with ALIGN/OpenROAD.
